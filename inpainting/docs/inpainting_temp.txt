# Seamless Collage v2 - Multi-Image & Flexible Layouts

## Overview

Extend the MVP (2-image horizontal blend) to support:

- **N images** (3, 4, 5, ... images)
- **Multiple layouts** (horizontal strip, vertical strip, grid)
- **Auto-layout** suggestions based on image count and dimensions

---

## Prerequisites

Complete MVP first:

- `inpainting/collage.py` - basic 2-image horizontal blend working
- `inpainting/inpainting_utils.py` - blend mask utilities

## Learning Track

### 1. Image Composition and Layout Algorithms

**What to learn:**

- How to calculate optimal image placement on a canvas
- Aspect ratio preservation strategies
- Grid packing algorithms (bin packing basics)

**Key terms:**

| Term | Meaning |

|------|---------|

| **Aspect Ratio** | Width/height ratio - must preserve when resizing |

| **Canvas** | The target output image dimensions |

| **Bin Packing** | Algorithm to fit rectangles efficiently in a space |

| **Justified Layout** | Like Google Photos - variable widths, same row height |

**Recommended reading:**

- Flickr Justified Layout: `https://github.com/flickr/justified-layout`
- CSS Grid concepts (transferable to image layouts)

---

### 2. Multi-Region Masking Strategies

**What to learn:**

- Handling multiple blend zones (not just one gap)
- T-junctions and cross junctions in grids
- Prioritizing which regions to inpaint first (or all at once?)

**Key concepts:**

```
Horizontal (3 images):
┌─────┬─────┬─────┐
│ A   │ B   │ C   │
│     │     │     │
└─────┴─────┴─────┘
      ↑     ↑
    gap1   gap2  (2 vertical blend zones)

Grid (4 images, 2x2):
┌─────┬─────┐
│ A   │ B   │
├─────┼─────┤
│ C   │ D   │
└─────┴─────┘
      ↑
   cross junction (4-way blend needed)
```

**Challenge:** Grid layouts have cross-junctions where 4 images meet - requires special handling.

## Supported Layouts

### 1. Horizontal Strip

```
┌────┬────┬────┬────┐
│ 1  │ 2  │ 3  │ 4  │
└────┴────┴────┴────┘
```

- All images same height
- Variable widths (preserve aspect ratio)
- N-1 vertical blend zones

### 2. Vertical Strip

```
┌────────┐
│   1    │
├────────┤
│   2    │
├────────┤
│   3    │
└────────┘
```

- All images same width
- Variable heights
- N-1 horizontal blend zones

### 3. Grid Layout

```
2x2:          2x3:           3x3:
┌───┬───┐     ┌───┬───┐      ┌───┬───┬───┐
│ 1 │ 2 │     │ 1 │ 2 │      │ 1 │ 2 │ 3 │
├───┼───┤     ├───┼───┤      ├───┼───┼───┤
│ 3 │ 4 │     │ 3 │ 4 │      │ 4 │ 5 │ 6 │
└───┴───┘     ├───┼───┤      ├───┼───┼───┤
              │ 5 │ 6 │      │ 7 │ 8 │ 9 │
              └───┴───┘      └───┴───┴───┘
```

- Uniform cell sizes
- Cross-junction blending
- Rows × Cols configurable

### Phase 3: Inpainting Strategy

Two approaches to evaluate:

| Approach | Pros | Cons |

|----------|------|------|

| **All-at-once** | Single inference, consistent style | Large mask area, may lose coherence |

| **Sequential** | Smaller regions, better control | Multiple inferences, potential inconsistency |

**Recommendation:** Start with all-at-once, add sequential as option.

## Auto-Layout Logic

```python
def auto_detect_layout(images: List[Image]) -> str:
    n = len(images)
    avg_aspect = mean([img.width / img.height for img in images])
    
    if n == 2:
        return "horizontal"  # Classic side-by-side
    elif n == 3:
        return "horizontal" if avg_aspect > 1 else "vertical"
    elif n == 4:
        return "grid"  # 2x2 is natural
    elif n in [6, 9]:
        return "grid"  # 2x3, 3x3
    else:
        return "horizontal"  # Default fallback
```
